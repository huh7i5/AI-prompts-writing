# 同一班渡船停航，告示和日记各写了什么？

[English](text-reading.en.md) · [返回写初稿的提示词](../../README.md#drafting)

课堂上要比较两段文字，只写“告示客观，日记主观”还不够。下面两段材料都是为练习虚构的。把整个框复制给 AI，看它能否用原文的词句解释这两种写法。

```text
给大学写作课写一段 100–160 字的中文短评。比较两份材料怎样写渡船停航，重点看时间是怎样写的，以及谁在做什么。两份材料各引用至少一个短语，逐字照录，并解释它支持哪一句判断。只用下面的材料。

材料一｜渡口告示（虚构）
自十月一日起，南湾渡口停航。请乘客改乘三路公交车，在东桥站下车。

材料二｜乘客日记（虚构）
十月一日。闹钟照旧在六点十分响。我走到巷口，才把手里的船票塞回口袋，转身去等三路车。
```

<details>
<summary>看一种写法及核对方法</summary>

告示用“自十月一日起”划出换乘的日期，接着写乘哪路车、在哪站下车。日记把这一天写到了六点十分。“照旧”说的是闹钟，出门的人却要改走另一条路。直到巷口，手里的船票才被塞回口袋。对写日记的人来说，改乘公交发生在上路的半途，旧习惯还留在手上。

**怎样核对**

把段末的“写日记的人”换成“全镇乘客”，再回头找证据。材料二只写了一个人在巷口收起船票，其他乘客怎样过这一天，还需要别的材料。

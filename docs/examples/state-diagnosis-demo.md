# 示例：智能判断写作状态、先给写作建议再辅助改稿（对话实录示范）

多数传统 Prompt 仓库需要用户先背熟编号再填表；而装入总控 Skill `ai-prompt-writing` 后，用户只需把手里现有的**半成品文字、混乱笔记和诉求**直接发过去，系统会按固定三段结构交付：
1. **写作状态判定与写作建议**（判断所处阶段 + 数据现状 + 最优先改进项）
2. **直接可用的改稿正文**（去 AI 腔与空泛自谦，同时死守数字、样本与限定条件）
3. **核查范围与待作者确认项**

---

## 一、 用户原始输入（未整理、未指定任务编号）

```text
$ai-prompt-writing 我手里只有一段刚拼出来的初稿片段，想发中文核心期刊，帮我顺一下：

"在人工智能飞速发展的背景下，本研究粗浅尝试探索课堂实时提示工具，显著提升了学生全部学习能力，
具有划时代意义。值得注意的是，虽然样本仅40人且局限性很多请专家批评指正，实验组平均分从75%提升到82%。"
```

---

## 二、 智能输出结构

### 1. 当前写作状态判定与写作建议
- **阶段与证据状态判定**：`IN_PROGRESS` · 对应 **阶段 6（`6.3 去套话` + `6.5 反防御与去夸大`）** 与 **阶段 7（`7.1 证据一致性自查`）**；属于中文期刊小论文（`journal_zh`）引言/摘要过渡片段。
- **三条具体写作建议（改前必看）**：
  1. **撤掉开头套话与越界夸大**：“在人工智能飞速发展的背景下”“显著提升全部学习能力”“划时代意义”均无证据支撑；且原文未提供统计检验 `p` 值，不能写“显著提升”。
  2. **清理空泛自谦，保留必要限定**：删去“粗浅尝试”“局限性很多请专家批评指正”等毫无信息量的道歉，但**必须保留“单门课程 / 样本 40 人”**这一决定结论外推边界的条件。
  3. **厘清指标口径**：`75%` 到 `82%` 属于 **7 个百分点（percentage points）**的绝对均值差，而不是相对提升 7%；另须确认“实验组/对照组”各自的样本量分配。

### 2. 直接可用的辅助改稿

> 在一门本科生课程测验（总样本量为 40 人）中，引入课堂实时提示工具后，实验组平均得分率为 82%，对照组为 75%（高 7 个百分点）。由于本研究仅基于单次测验观测，该结果尚不能直接外推至跨学期课程或不同学科场景，也尚未排除原有分组差异的潜在影响。

### 3. 本次核查范围与待作者确认项
- **实际核查范围**：仅审阅本次提供的单段 88 字草稿，未见到完整方法与统计检验输出（其余章节与参考文献列为 `[未核对]`）。
- **待作者确认（不替作者编造）**：
  1. 总样本 `N=40` 中实验组与对照班各有多少人？分组方式是否为随机分配？
  2. 原材料是否有 $t$ 检验 / 效应量或标准差输出？若有，请在结果节补充后再定是否使用统计显著性表述。

# 示例：中文硕博学位大论文跨章改稿、数值冲突扫描与审稿返修（`thesis_zh`）

与 4–8 页的期刊小论文不同，中文硕博学位大论文（依据国标 **GB/T 7713.1**《学位论文编写规则》）动辄 5–7 章，最高频的致命硬伤是**“第 1 章摘要/绪论写的样本量与第 3 章实证结果打架”**以及**“导师或盲审专家要求补分析后，正文写成了已完成”**。

本示例演示如何用 `check_numbers.py` 抓出跨章数值冲突，并按任务 `9.2 / 9.3` 完成大论文多章联动返修。

---

## 一、 原始两章片段（存在典型跨章口径打架）

**第 1 章 绪论片段 (`ch1_intro.md`)**：
> 本文发放问卷样本量 N = 320，覆盖 4 所高校本科生，整体有效回收率为 85%。

**第 3 章 实证分析片段 (`ch3_empirical.md`)**：
> 剔除缺失值后最终进入回归的样本量 n=288，其中实验班 144 人、对照班 144 人，平均分提升 6.5 个百分点。

**导师/盲审意见 #1**：
> “第 1 章写 `N=320`，第 3 章写 `n=288`，两者为何相差 32 份？另外第 3 章仅凭平均分差 6.5 个百分点就推论教学方法对全部课程有效，表述过强，建议补充稳健性检验或说明样本差异。”

---

## 二、 实跑 `check_numbers.py` 跨章扫描输出（真实终端实测）

```bash
python .agents/skills/paper-audit-submission/scripts/check_numbers.py --inputs ch1_intro.md ch3_empirical.md
```

实际输出（JSON 摘要）：

```json
{
  "total_blocks_scanned": 4,
  "distinct_sample_sizes": [288, 320],
  "has_sample_size_variation": true,
  "unit_bearing_values": {
    "%": { "distinct_values": [85.0] },
    "个百分点": { "distinct_values": [6.5] }
  },
  "alerts": [
    {
      "code": "POTENTIAL_SAMPLE_SIZE_DISCREPANCY",
      "distinct_values": [288, 320],
      "message": "Detected multiple sample-size numbers across locations: [288, 320]. Verify whether these represent total vs subgroup vs conflicting versions; never average or pick one silently."
    }
  ]
}
```

**核心守则触发**：在作者尚未确认 `320` 与 `288` 究竟是“总发放量 vs 剔除缺失后分析样本”还是前后版本遗留错误前，**绝不私自删改或平均数字**；未真实补做稳健性检验前，**绝不把计划补做写成已完成**。

---

## 三、 大论文联动改稿与逐条回复表（按任务 9.2 + 9.3 输出）

### 1. 正文同步修订建议（需作者确认口径槽位）

- **第 1 章 绪论（明确口径区分，不与第 3 章冲突）**：
  > 本文在 4 所高校累计回收有效问卷 320 份（`[待作者确认：核对原始发放份数与 85% 回收率分母口径]`），经 `[待补：缺失值与异常作答剔除标准]` 筛选后，最终纳入第 3 章主回归分析的样本量为 `n = 288`（实验班 144 人、对照班 144 人）。
- **第 3 章 实证分析（收窄结论外推边界）**：
  > 在最终纳入回归的 288 名样本（实验班与对照班各 144 人）中，实验班测验平均分较对照班高 6.5 个百分点。鉴于本分析目前仅对比了上述 4 所高校的特定课程样本，该差异尚不能直接推广至全部学科课程。

# 给写作 Agent 的任务

我想写一篇简短的中文研究文章，看看华盛顿 Capital Bikeshare 的工作日和非工作日有什么不同。请用 UCI 的 Bike Sharing 数据集，取 2011 和 2012 两年的日记录。先查清数据里的“工作日”和两类用户各指什么，再计算。

我关心两个问题。工作日和非工作日相比，注册用户、临时用户的日均租借量是否朝同一个方向变化？把两年拆开看，各自的方向是否一致？请顺带说明只看总量会漏掉什么。

请用一张表列出两年分别计算以及两年合并的结果。每行写明年份和类别，给出两种日子的均值和差值，差值按工作日减非工作日计算。正文写给第一次阅读定量研究的学生，解释怎么算、差多少、数据能说明什么。给出数据来源及实际读到的相关文献，方便回查。

期望交付一篇可读的文章、一份能从原始日表复算的脚本和一份审查记录。审查时逐行核对均值、差值、单位和天数，并区分数据里的发现与对原因的推测。

[UCI Bike Sharing 数据页](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset)

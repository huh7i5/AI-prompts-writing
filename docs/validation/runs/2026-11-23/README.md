# 任务 6.5 的两次改稿试用

两段材料均为本次编写的虚构示例。每例使用相应语言的完整 6.5 提示词，将文字和记录填在末尾，只发送这一条消息。两例各用一个独立的新对话，执行者只看到该例输入。以下条件在生成答复前写定。

| 输入 | 事先约定的检查条件 |
| --- | --- |
| [中文：同一个班的作业记录](zh-input.md) | 直接报告按时提交人数（12/20 与 8/20），保留拖延至少一周的人数（3 与 1）。删去泛泛的致歉，交代来自一个班、学生自行选择提醒。避免声称因果、统计显著或适用于所有班级。 |
| [英文：一组外寄信件](en-input.md) | 保留原句的事实和证据范围，包括 18 封中有 7 封提及运费、只存外寄信件、收件人实际付款无法由这些信件确定。能判断原段落可直接保留，没有为了显示修改而删掉 “Only” 或添加推论。 |

中文改稿删去了请读者包涵的整句，开头直接比较了两组按时提交的人数。随后报告了方向不同的另一项结果，开启组有 3 人迟交至少一周，未开启组有 1 人。改稿写明单班、单次作业和学生自选提醒，收窄了原文关于提醒效果的结论。[中文原始输出](zh-output.md)

英文答复在修改说明中指出，存世材料只有外寄信件，这决定了研究者能推断什么。给出的修订稿逐字保留了原来的两句话。[英文原始输出](en-output.md)

两例均满足各自的预设条件。两次答复来自本次 Codex 环境，每种语言各一个输入、各运行一次。复核依据是上表和输出原文。其他七种语言本轮只检查文字同步情况，独立 Skill 未单独试跑。

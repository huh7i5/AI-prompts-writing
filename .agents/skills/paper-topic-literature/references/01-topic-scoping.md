# 阶段一细则：条件驱动选题与问题收敛（任务 1.1 & 1.2）

本规程用于处理 **1.1 从兴趣和现有条件里找选题** 与 **1.2 把大方向变成一个具体问题**。

---

## 一、 学科与研究方式适配表（严禁套用单一实验模板）

在评估可行性或提出研究问题前，必须先根据用户的专业背景、技能基础与可用资源，匹配恰当的研究方式：

| 研究方式 | 适用的典型资源条件 | 关注的核心要素 | 严禁强加的错位要求 |
| :--- | :--- | :--- | :--- |
| **历史档案 / 文本细读 / 人文阐释** | 公开报刊档案、地方志、文学文本、判例汇编；无需统计建模或访谈经费 | 史料/文本的时间跨度与编纂背景、叙事视角差异、核心概念流变、反例文本、史料局限 | 严禁要求随机对照实验、问卷量表、分类准确率、`p` 值或统计显著性检验 |
| **质性实证（访谈 / 田野 / 案例）** | 可接触特定受访群体、公开讨论文本或机构个案记录 | 抽样与准入边界、资料收集深度、编码与主题提炼逻辑、研究者立场、反面个案、伦理知情同意 | 严禁把小样本访谈强行包装成大样本总体推断或要求计算显著性水平 |
| **定量实证 / 计算实验** | 公开数据集、可运行代码与算力、规范调查数据或实验室记录 | 变量操作化定义、基线/对照公平性、样本纳入排除、评价指标权衡、不确定性与替代解释 | 资源不足以做因果识别（如横截面观测、无随机化）时，严禁把相关问题设计成强因果证明 |
| **理论推导 / 形式化分析 / 规范法学** | 既有公理/定理体系、模型假设、法律条文与学说争议 | 核心定义边界、前提假设合理性、推导闭合性、边界反例、与既有理论的兼容性 | 严禁虚构经验数据集或强迫补充湿实验/问卷调查 |
| **文献综述（范围综述 / 批判性综述）** | 明确的文献数据库访问权限、充足的筛选与精读时间 | 检索边界、纳入排除标准、方法与结论异质性来源、证据质量等级 | 时间紧或单人课程作业无完整筛选记录时，只建议做“聚焦型文献评述”，不建议宣称做 PRISMA 系统综述 |

---

## 二、 任务 1.1 执行规程：从兴趣和现有条件里找选题

### 1. 前置可行性诊断
先用 2–4 句话明确指出用户当前的**硬约束边界**（例如：“六周时间 + 仅限两份校内公开地方报纸数字档案 + 本科文本细读基础 + 无经费无访谈”）能支撑什么体量与什么方法的研究，提前排除超出资源上限的方向（如跨省田野调查、大规模人工标注建模等）。

### 2. 输出 3 个可横向比较的候选方向
每个候选方向必须包含以下 6 个具体要素（避免空泛大词）：
1. **具体研究问题**：写成一句边界清晰、可回答的问句（限定时间段、研究对象、核心比较维度或分析切口）。
2. **论证价值所需的证据**：回答该问题具体要从现有材料里提取什么内容（如特定时期的报道频次与措辞变化、不同版面/群体的归因差异、特定数据集上的延迟-准确率权衡记录）。
3. **适配的研究方法**：贴合用户技能栈的具体操作方法（如按时间节点抽样结合话语细读、比较案例分析、消融对照测试等）。
4. **现有条件下的可行性**：为什么在给定的时间、篇幅（如 5000 字课程论文）与材料范围内做得完。
5. **主要困难与风险**：最可能卡壳的地方（如某年份档案缺页、关键词检出率过低、混杂事件干扰解释）及收窄预案。
6. **下一步立即可做的查证动作**：先去现有档案/数据库里试搜哪几个词、核实哪几条样本，以决定是否正式定题。

### 3. 1.1 边界禁令
- 这里输出的全部是**候选研究方向**，绝不写成“填补学界空白”或“前人从未关注”的已验证创新点。
- 不替用户直接拍板选定某一个题目，而是说明三个方向在“材料稳妥度 vs 分析深度”上的取舍，交由用户先做小规模试查后再定。

## 三、 任务 1.2 执行规程：把大方向收窄成具体问题

### 1. 先做“三层事实剥离”
在提出问题前，先把用户提供的材料拆清楚：
- **已有文献/常识结论**：材料中已明确提及的前人发现或背景规则（未提供文献则写“材料未提供已核实前人文献”）；
- **用户的实际观察或手头线索**：用户自己看到的现象、初步跑出的现象或手头已有的样本；
- **待检验的假设/猜测**：尚未被证据证实的因果解释、机制推测或优劣判断。

### 2. 收窄为 1–3 个具体研究问题
按由稳妥（描述/比较型）到进取（机制/条件边界型）的梯度给出 1–3 个问题，每个问题交代：
- **研究对象与分析单位**（谁、什么场景、什么范围）；
- **回答该问题所需的最小证据集**；
- **至少 1 个需要排除或讨论的替代解释**（例如：观察到的差异究竟来自工具本身，还是来自使用者原本的能力差异/自选择效应）；
- **结论的适用范围与边界**。

### 3. 候选贡献与缺口标注
- 没有真实数据或结果前，所有“预期贡献”一律标为**候选贡献（待证据检验）**。
- 明确列出推进到下一阶段（`2.1 文献检索` 或 `3.1 研究方案`）前**最急需补充核实的 2–3 项关键信息**。

## 四、 流水线模式工件落地（当启用 `CAP_WORKSPACE` 时）

若处于端到端流水线工作区模式，完成 `1.1` 或 `1.2` 且用户选定方向后，按 [`templates/01_topic_spec.yaml`](../templates/01_topic_spec.yaml) 模板写出 `01_topic_spec.yaml`，将 `status` 设为 `"SCOPED_PENDING_LITERATURE"`，供 `2.1` 文献检索与下游研究方案工位直接读取。

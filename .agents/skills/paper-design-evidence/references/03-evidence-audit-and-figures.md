# 阶段四细则：研究记录索引、分析/推导审查与图表图注规范（任务 4.1, 4.2, 4.3）

本规程用于处理 **4.1 整理研究笔记和材料**、**4.2 检查分析过程和结论是否合理（含理论反例检查）** 与 **4.3 安排图表，写清图表说明**。

---

## 一、 任务 4.1：整理可追溯的研究记录与证据索引

把零散的实验输出、代码记录、访谈转写、档案摘录或推导草稿整理成支持后续写作与核查的索引表：

1. **按研究范式保留完整追溯链**：
   - **定量/实验**：原始数据文件名与版本 → 清洗与样本排除记录 → 具体分析脚本/设置 → 输出数值与图表位置；
   - **质性/档案**：访谈编号或档案卷宗页码 → 编码规则与主题归类 → 代表性引文位置 → 反例材料记录；
   - **理论/证明**：核心定义与符号约定 → 公理/前提假设 → 各引理推导步骤 → 已知边界条件与反例；
   - **综述**：检索日期与检索式 → 初筛/复筛计数 → 纳入文献提取表版本。
2. **强制五要素索引列**：
   `主张或结果摘要 | 原始来源与版本号 | 处理或论证步骤 | 已知限制/负结果/计划偏离及发生时间 | 待补记录`
3. **安全与诚实边界**：
   - **只整理实际读到的内容**，未提供的附件或本地路径严禁声称“已打开核实”；
   - 涉及受访者姓名、学号、联系方式等个人信息时，遵循**最小必要原则**，在索引中主动提示脱敏并隐去无关隐私字段。

---

## 二、 任务 4.2：审查分析、解释或推导能否支撑结论（重点防呆规程）

本任务要求像严谨的同行合作者一样检验“材料 → 过程 → 结论”之间有没有断裂或漏洞：

### 1. 按研究方式定向抓关键漏洞（绝不张冠李戴）
- **理论分析与数学证明（如黄金用例 `T10`）**：
  1. 逐一检查核心定义是否清晰、隐含前提是否写出；
  2. 逐行检查每步推导是否真的成立（特别警惕不等式两边平方、取倒数、同乘可能为负或为零的量、取极限交换次序、除以零、非凸性、边界退化点等常见跳步）；
  3. **主动构造具体反例（Counterexample）**：一旦发现推导步骤依赖额外条件，立即给出一个最简单、可当场验算的具体反例（例如针对“由 $a < b$ 推出 $a^2 < b^2$ 进而宣称 $f(x)=x^2$ 在全体实数上严格递增”，直接给出 $a = -2, b = -1$，满足 $-2 < -1$ 但 $(-2)^2 = 4 > (-1)^2 = 1$）；
  4. **给出最小修正/收窄方案**：说明补上什么前提条件（例如限定定义域为非负实数 $[0, +\infty)$）推导即可成立，并明确指出这会如何**收窄作者原本想写的主张**；
  5. **双重边界禁令**：对纯理论推导任务，**严禁索要样本量、`p` 值或随机对照实验**；同时，除非实际调用了 Coq / Lean / Isabelle 等交互式定理证明器并验证通过，**严禁声称“已完成完整形式化验证（Formal Verification）”**。
- **定量实证分析**：检查对照组与测试条件是否公平可比、样本流失与排除是否引入偏差、分布与独立性假设是否满足、是否存在未校正的多重比较、是否把相关性或单次观测拔高成了因果或普适规律。
- **质性分析**：检查主题提炼是否有具体原始语料支撑、是否存在选择性摘录而忽略反面个案、研究者的预设是否主导了解释、取样范围能否支撑推广。
- **综述分析**：检查纳入标准是否前后一致、不同文献结论冲突时是否分析了研究设计与异质性来源。

### 2. 复现声明红线与强制四栏输出
- 没有原始数据或未实际运行代码时，明确说明本次审查仅基于用户提供的摘要/公式片段；**只有实际运行了代码并保留输入、步骤与输出，才能使用“已重新计算”或“已复现”字样**。
- 避免只列一堆教科书式方法建议却不判断眼前材料；也不要为凑出显著结果建议“换个指标试试（p-hacking）”。
- 完成时必须清晰标出四部分：
  1. **当前材料已能支持的主张（或收窄后可成立的主张）**；
  2. **具体依据（含验算过程或反例）**；
  3. **受限于缺失材料仍不能判断的部分**；
  4. **最小补充或修改下一步**。

## 三、 任务 4.3：安排图表分工并撰写严谨图题、图注与表注

### 1. 先审图表职责，再给方案与文字
- 判断每张拟设图表在全文论证中承担什么独立任务：哪些信息用表格比柱状图更精确？哪两张图内容重复可以合并？是否漏掉了关键基线或样本分布说明？
- **诚实声明**：本步骤只提供图表结构建议与可直接使用的图题/图注/表注文本；**未实际运行绘图代码产出图片前，严禁写“图已画好”**。

### 2. 图题、图注与表注必填要素（缺一标 `[待补]`）
每段图注/表注必须让读者无需翻回正文就能看懂数字口径：
- **研究对象与测试/观测条件**；
- **物理量单位**（如 `ms`、`kg/m³`、`%`）；
- **确切样本量 `n / N`**（区分总体样本量与各分组样本量；未知标 `[待补样本量 N]`）；
- **误差线、括号或阴影带的真实统计定义**（必须写明究竟是标准差 `SD`、标准误 `SE`、四分位距 `IQR` 还是 `95% CI`；作者未提供时标 `[待补误差标记含义]`，绝不擅自猜填 `± SD`）。

### 3. 数值计算与视觉诚信红线
- **百分比 vs 百分点严格区分**：从 `89%` 到 `90%` 的绝对差必须写为 **1 个百分点（1 percentage point）**，不得笼统写成“提高了 1%”；从 `40 ms` 降到 `12 ms` 的相对变化需写清公式 $(40 - 12) / 40 = 70\%$。
- 没有统计检验结果时，图注只做描述性陈述，不得写“显著高于（significantly higher）”。
- 严禁建议通过截断纵坐标起点、挑有利子集分组或隐藏负向误差线来制造视觉优势。
